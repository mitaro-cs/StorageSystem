# groupbase

Сервис для студенческой группы на своём сервере: новости, домашние задания и материалы по предметам.
Данные группы не покидают её сервер: без телеметрии, внешних шрифтов и трекеров.

> Проект в разработке. Полная документация появится в `docs/` к релизу v0.1.0.

## Сборка из исходников

Нужны JDK 21+ и Node.js 22+.

```bash
make build
```

```bash
java -jar target/groupbase.jar serve
```
