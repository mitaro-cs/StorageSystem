# groupbase

**Сайт и приложение для учебной группы на своём сервере.** Домашние задания, новости и материалы по
предметам в одном месте — с телефона, компьютера и даже без интернета. Данные группы хранятся только
у неё: без рекламы, трекеров, внешних шрифтов и «облаков».

## Зачем

В группе всё обычно разбросано: задания — в чате, методички — в облаке у старосты, перенос пары — в
сообщении, которое утонуло за вечер. groupbase собирает это в одно место, где:

- **сразу видно, что сдать** — главная показывает ближайшие дедлайны по дням и просроченное;
- **ничего не теряется** — материалы разложены по предметам и папкам, поиск понимает русские окончания;
- **работает без интернета** — в метро и в аудитории без сети всё открывается, а сделанное уйдёт на
  сервер, когда связь вернётся;
- **приходит напоминание** — push-уведомление о новом задании и за сутки до срока;
- **данные принадлежат группе** — сервер работает прямо на компьютере старосты: скачал приложение,
  нажал «Открыть доступ», отправил ссылку. Можно и на VPS или домашний мини-ПК. Один сервер — одна
  группа или целый поток.

## Возможности

### Для студентов
- **«Сегодня»**: ближайший дедлайн крупной карточкой, задания по дням, срочные новости.
- **Домашние задания**: неделя, календарь, просроченное; сложность (легко, средне, сложно); личная
  отметка «сделано» (видна только вам), файлы-вложения, комментарии.
- **Файлы** одним деревом с путём: «Файлы › Физика › Материалы › папка» и «Файлы › Физика › Задания ›
  Лабораторная №3». PDF, картинки, видео, аудио и текст открываются **прямо в приложении** — на
  телефоне тоже, листаются свайпом; остальное — «Скачать».
- **Поиск** по заданиям, новостям, материалам и предметам: «задача» найдёт и «задачи», «расчет» — «расчёт».
- **Уведомления**: колокольчик в приложении и push на телефон — новые задания, новости, напоминание
  за сутки до срока, утренняя сводка. Что присылать, выбирается переключателями.
- **Без интернета**: данные группы хранятся на устройстве. Без сети можно читать всё, отмечать
  выполненное, комментировать и даже публиковать — всё уйдёт на сервер по порядку, когда появится сеть.
  Файлы материалов сохраняются заранее (до 20 МБ, все или только открытые — на выбор).
- **Как приложение**: ставится на экран «Домой» iPhone и Android, на Windows и macOS — из браузера,
  без магазинов. Пошаговый мастер установки внутри.
- **Вход без ввода**: выбрать свой аккаунт на знакомом устройстве или войти по QR-коду с телефона,
  как в мессенджерах. Пароль можно не придумывать — «Придумать за меня» даст фразу вроде
  `лиса-маяк-пирог-42`.
- **Со второго устройства**: та же ссылка-приглашение на ноутбуке не требует новой регистрации —
  «У меня есть аккаунт» → вход по паролю или по QR-коду с телефона.
- **Удобства**: светлая и тёмная тема, иконки предметов, палитра команд `Ctrl/⌘+K`, горячие клавиши,
  свайп «назад», выгрузка всех своих данных в ZIP. На телефоне страница не прыгает от касаний и
  двойного нажатия и сразу занимает весь экран.

### Для старост
- **Предметы** с преподавателем, цветом и иконкой: больше 70 иконок на выбор (Σ, атом, колба, код,
  сеть, язык, гантель…), а без выбора иконка подбирается по названию сама. Общий предмет для
  нескольких групп потока.
- **Чаты в Telegram**: закрепите чат группы или канал — ссылка появится на главной у всех рядом с
  быстрыми действиями; у предмета — свой чат, кнопка на его странице. Принимаются `t.me/…`, `@имя`
  и ссылки-приглашения.
- **Публикация** заданий с файлами и новостей (срочные, закреплённые) в пару касаний.
- **Люди** — в личном кабинете и в «Участниках»: все одногруппники с ролями, поиск, меню действий.
  **«Добавить людей»**: вписать ФИО одного человека — сразу QR-код, он сканирует и сам задаёт пароль;
  вставить список группы — у каждого своя ссылка с QR, лист можно распечатать; или одна
  ссылка-приглашение с **QR-кодом на весь экран** для проектора.
- **Сброс пароля** за минуту: QR-код, который человек сканирует своим телефоном.
- **Права**: заместителю можно разрешить создавать аккаунты и предметы, студентам — предлагать
  материалы на проверку.
- **Модерация**, журнал действий, **архив группы в ZIP**, который открывается без groupbase
  (участники — в Excel, новости и задания — текстом, материалы — по папкам).
- Чек-лист **«Первые шаги»** на главной: предметы → приглашение → первое задание → приложение →
  уведомления.

### Для хоста и администратора
- **Приложение для Windows и macOS**: сервер группы внутри, окно с сайтом, значок в трее,
  автообновление кнопкой. Доступ одногруппникам — бесплатные российские туннели CloudPub или
  fxTunnel (работают с VPN и без), локальная сеть или свой адрес.
- **Резервные копии** раз в сутки — в папку Яндекс Диска, iCloud Drive или OneDrive; восстановление и
  переезд на другой компьютер в пару кликов. Панель «Состояние»: место на диске, новая версия.
- **Роли**: администратор назначает старост, замов, **модераторов и администраторов сайта** — в том
  числе себе (последнего администратора снять нельзя).
- **Внешний вид**: фон страниц входа и регистрации — встроенные рисунки или своя картинка (фото
  корпуса, группы).
- **Режим управления**: спрятать кнопки администратора и пользоваться сайтом как участник.
- Одна группа или несколько (поток, кафедра) на одном сервере.
- Обязательная двухфакторная защита для администраторов и модераторов, резервные коды.
- Логины участников видят только староста и администратор.

### Что такое «сайт» (инстанс)

**Сайт** — это весь ваш groupbase целиком: одна группа или несколько групп потока, их общие
настройки и администраторы. В технических текстах его называют *инстансом* — это одно и то же.

| Роль | Где действует | Что может |
|---|---|---|
| Администратор сайта | весь сайт | всё: группы, роли, сервер, доступ из интернета, копии. Обычно это хост |
| Модератор сайта | все группы | скрывать лишнее и блокировать нарушителей, но не настройки |
| Староста, зам | своя группа | приглашать, публиковать, назначать роли (в пределах прав) |
| Студент | своя группа | читать, отмечать сделанное, комментировать |

## Приватность и безопасность

- **Всё на вашем сервере.** Никакой телеметрии и внешних запросов из браузера: шрифты и иконки
  встроены, CSP `default-src 'self'` без inline-скриптов.
- **Файлы шифруются** на диске (AES-256-GCM, у каждого файла свой ключ), имена на диске — случайные UUID.
- **Пароли** — Argon2id; сессии — случайный токен в cookie `HttpOnly`, `Secure`, `SameSite=Strict`,
  в базе только его хеш; защита от подбора с нарастающей блокировкой.
- **Права проверяются на сервере**, изоляция групп покрыта тестами; поиск, уведомления и
  синхронизация показывают только то, что пользователю разрешено.
- **Push-уведомления** зашифрованы для устройства (RFC 8291) — службы браузеров их не видят;
  сервер отправляет только на домены служб push.
- IP-адреса в журнале хранятся 30 дней; каждый может скачать свои данные или удалить аккаунт.
- **Туннель (CloudPub или fxTunnel)** передаёт трафик участников на компьютер хоста, как обычный
  провайдер: HTTPS заканчивается на его сервере. Данные хранятся только у хоста. Для полной
  независимости — свой домен или сервер (раздел «Свой сервер»).

Как сообщить об уязвимости — в [SECURITY.md](SECURITY.md).

## Быстрый старт: приложение для компьютера

Сайт группы работает **на компьютере старосты** (или того, кто вызвался быть «хостом»): ни сервера,
ни домена, ни денег не нужно. Одногруппники заходят по ссылке с телефона.

1. **Скачайте установщик** со страницы [последнего выпуска](https://github.com/mitaro-cs/StorageSystem/releases/latest):

   | Компьютер | Файл |
   |---|---|
   | Mac на M1–M4 (Apple Silicon) | `groupbase-…-macos-apple-silicon.dmg` |
   | Mac на Intel | `groupbase-…-macos-intel.dmg` |
   | Windows 10 и 11 | `groupbase-…-windows-setup.exe` |

2. **Установите.** Программа бесплатная и без платной подписи разработчика, поэтому система один раз
   переспросит:
   - **macOS**: перетащите groupbase в «Программы» и откройте. Если macOS скажет, что не может
     проверить разработчика, — «Системные настройки» → «Конфиденциальность и безопасность» →
     «Всё равно открыть».
   - **Windows**: если появится «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом
     случае». Права администратора не нужны.
3. **Первый запуск.** В окне groupbase — название группы, ваше ФИО и пароль (можно «Придумать за
   меня»). Вы станете администратором сайта и старостой группы.
4. **Откройте доступ группе.** «Настройки» → «Сервер» → «Интернет — CloudPub» → войти (бесплатный
   российский сервис, регистрация за минуту) → «Открыть доступ». Появится постоянная ссылка вида
   `https://wildly-suitable-fish.cloudpub.ru` и QR-код. Работает с VPN и без. Есть и второй вариант —
   fxTunnel с адресом на выбор (`имя.fxtun.ru`).
5. **Пригласите одногруппников**: «Настройки» → «Приглашения» → QR на весь экран или ссылка в чат.
   Они регистрируются и ставят приложение на экран «Домой».

Подробнее, с ответами на частые вопросы — в [docs/desktop.md](docs/desktop.md).

### Когда компьютер выключен

Сайт недоступен, но **у одногруппников всё остаётся**: задания, новости и материалы хранятся на их
устройствах. Можно читать, отмечать выполненное, писать комментарии и публиковать — всё отправится,
когда компьютер снова включится. Чтобы сайт был доступен чаще, в меню groupbase (значок в строке меню
macOS или у часов на Windows) включите «Запускать при входе в систему» и «Не давать компьютеру
засыпать». Закрытое окно сайт не выключает — только «Выйти».

### Данные и резервные копии

Всё хранится на компьютере хоста (macOS — `~/Library/Application Support/app.groupbase`, Windows —
`%APPDATA%\app.groupbase`). Копия делается сама раз в сутки; в «Настройки» → «Сервер» можно выбрать
папку Яндекс Диска, iCloud Drive или OneDrive — тогда копии уедут в облако. Переезд на новый компьютер:
скачайте копию, установите groupbase и при первом запуске нажмите «Восстановить из резервной копии».

### Обновления

Приложение само проверяет выпуски на GitHub. Когда выходит новая версия, в меню значка появляется
«Обновить до версии …», а в «Настройки → Сервер → Состояние» — кнопка «Обновить сейчас»: groupbase
скачает обновление, остановит сервер, установит и откроется заново. Обновления подписаны ключом
проекта — подменённый файл не установится. Участникам ничего делать не нужно: их приложение
обновится при следующем открытии сайта.

### Режим управления

Хосту не обязательно всё время видеть кнопки администратора: переключатель «Режим управления» (в
профиле и в боковой панели) прячет приглашения, права, модерацию и настройки сервера — сайт выглядит
как у участников, а публиковать новости и задания по-прежнему можно.

## Свой сервер (для опытных)

Тот же groupbase можно поставить на VPS или домашний мини-ПК. Нужны **JDK 21+** и **Node.js 22+**
(или `groupbase.jar` со страницы выпуска — тогда только Java).

```bash
git clone https://github.com/mitaro-cs/StorageSystem.git groupbase
cd groupbase
make build
java -jar target/groupbase.jar serve
```

Сервер напечатает ссылку вида `http://localhost:8080/setup?code=…` — откройте её: код первичной
настройки уже в ней. Администратору сразу предложат включить двухфакторную защиту — понадобится
приложение-аутентификатор (Яндекс Ключ, Google Authenticator, Aegis) — и сохранить резервные коды.

Данные хранятся в каталоге `./data` (база SQLite, зашифрованные файлы и ключи в `data/secrets`),
резервные копии — в `data/backups` (раз в сутки, «Настройки» → «Сервер»).

Для телефонов сайту нужен адрес в интернете и HTTPS. Проще всего поставить перед groupbase
[Caddy](https://caddyserver.com) — он сам получит сертификат:

```caddyfile
group.example.ru {
	reverse_proxy 127.0.0.1:8080
}
```

и запустить groupbase с адресом сайта:

```bash
GROUPBASE_BASE_URL=https://group.example.ru java -jar target/groupbase.jar serve
```

### Настройки

Всё задаётся переменными окружения или файлом `groupbase.toml` (`serve --config groupbase.toml`;
у приложения для компьютера — `groupbase.toml` в каталоге данных).

| Переменная | По умолчанию | Что это |
|---|---|---|
| `GROUPBASE_DATA_DIR` | `./data` | где хранить базу, файлы и ключи |
| `GROUPBASE_BASE_URL` | — | адрес сайта, например `https://group.example.ru` |
| `GROUPBASE_HTTP_ADDRESS` | `127.0.0.1` | на каком адресе слушать (`0.0.0.0` — все) |
| `GROUPBASE_HTTP_PORT` | `8080` | порт |
| `GROUPBASE_HTTP_INSECURE` | `false` | работа без HTTPS (только для локальной сети и проверки) |
| `GROUPBASE_TIMEZONE` | `Europe/Moscow` | часовой пояс для сроков и утренней сводки |
| `GROUPBASE_UPLOADS_MAX_FILE_MB` | `50` | лимит размера одного файла |
| `GROUPBASE_AUTH_REQUIRE_STAFF_TOTP` | `true` | обязательная 2FA для администраторов и модераторов |
| `GROUPBASE_PUSH_ENABLED` | `true` | push-уведомления |
| `GROUPBASE_PUSH_SUBJECT` | адрес сайта | контакт администратора для служб push (`mailto:` или `https://`) |
| `GROUPBASE_BACKUP_ENABLED` | `true` | ежедневные резервные копии |
| `GROUPBASE_BACKUP_AT` | `03:30` | время копии (если компьютер был выключен — сразу после включения) |
| `GROUPBASE_BACKUP_KEEP` | `14` | сколько последних копий хранить |
| `GROUPBASE_BACKUP_DIR` | `data/backups` | каталог копий |
| `GROUPBASE_UPDATE_CHECK` | `true` | раз в 12 часов спрашивать GitHub о новой версии |
| `GROUPBASE_APP_KEY`, `GROUPBASE_FILES_KEY`, `GROUPBASE_VAPID_KEY` | создаются в `data/secrets` | ключи, если хранить их вне каталога данных |

За обратным прокси адрес посетителя и HTTPS берутся из `X-Forwarded-For` и `X-Forwarded-Proto`, но
только если прокси работает на этой же машине. Если прокси в другом контейнере, задайте его адреса в
`SERVER_TOMCAT_REMOTEIP_INTERNAL_PROXIES` (регулярное выражение).

## Как пользоваться

**Староста, первый день:**
1. Установите приложение, пройдите «Первый запуск» и откройте доступ группе («Настройки» → «Сервер»).
2. «Предметы» → «+ Предмет» для каждого предмета семестра.
3. «Участники» → «Добавить людей»: вставьте список группы или добавляйте по одному — с QR-кодом.
   Или «Ссылкой» → «На весь экран» — покажите на паре.
4. Опубликуйте первое задание: «+ Задание» на главной.

**Студент:**
1. Отсканируйте QR-код или откройте ссылку из чата, впишите ФИО и пароль (или «Придумать за меня»).
2. Установите приложение: на главной есть чек-лист и мастер «Установить на телефон».
3. Включите уведомления в профиле — и всё, задания будут приходить сами.

**Второе устройство?** Откройте ту же ссылку или сайт и нажмите «У меня есть аккаунт» — войдите
паролем или отсканируйте QR-код телефоном, где уже вошли. Регистрироваться второй раз не нужно.

**Забыли пароль?** Попросите старосту: он покажет QR-код для сброса.

```mermaid
flowchart LR
  subgraph Устройство
    UI[Интерфейс SvelteKit] --> IDB[(Копия данных<br/>IndexedDB)]
    UI --> SW[Service Worker<br/>офлайн, файлы, push]
  end
  UI -- HTTPS /api --> TUN[Туннель fxTunnel<br/>или свой прокси]
  TUN --> API[Spring Boot<br/>на компьютере хоста]
  SHELL[Приложение Tauri<br/>окно, трей] -- stdin/stdout --> API
  SW -. push .- PUSH[Службы push браузеров]
  API --> DB[(SQLite WAL<br/>FTS5, журнал изменений)]
  API --> FILES[(Файлы<br/>AES-256-GCM)]
  API -- RFC 8291/8292 --> PUSH
```

- **Сервер** — Java 21 + Spring Boot 4 (виртуальные потоки), SQLite в режиме WAL, миграции Flyway,
  явный SQL без ORM. Интерфейс собирается внутрь одного `jar`.
- **Интерфейс** — SvelteKit 2 + Svelte 5 (SPA), ≈100 КБ JS на страницу, без внешних зависимостей
  во время работы.
- **Офлайн** — журнал изменений на триггерах SQLite и `/api/sync`: сервер отдаёт изменения после
  курсора уже с учётом прав; действия без сети копятся в очереди на устройстве.
- **Поиск** — SQLite FTS5 с упрощённым стеммингом русских окончаний.
- **Push** — собственная реализация шифрования Web Push и подписи VAPID, проверенная на примере из RFC.
- **Приложение для компьютера** — оболочка на Tauri 2 (Rust, системный WebView) со встроенной
  минимальной Java (jlink, ~55 МБ). Сервер — дочерний процесс; когда компьютер хоста выключен, туннель
  отвечает своей страницей, и приложение участника по метке `X-Groupbase` понимает, что показывать
  сохранённое.

## Разработка

```bash
make dev    # бэкенд на :8080 и vite на :5173 с прокси /api
make test   # тесты бэкенда (JUnit, покрытие ≥ 70%) и фронтенда (Vitest)
make lint   # форматирование, javac -Werror, ESLint, Prettier, svelte-check
make e2e    # сквозные сценарии Playwright против собранного jar
make desktop      # установщик приложения для этой ОС (нужен Rust: https://rustup.rs)
make desktop-run  # приложение из исходников, данные — в ./data-desktop
```

Выпуск: тег `v1.2.3` → GitHub Actions соберёт `.dmg` для обоих видов Mac, установщик для Windows и
`groupbase.jar` и выложит их на страницу выпусков.

Структура и соглашения — в [CLAUDE.md](CLAUDE.md). Коммиты — [Conventional Commits](https://www.conventionalcommits.org/ru/),
интерфейс и сообщения об ошибках — на русском.
